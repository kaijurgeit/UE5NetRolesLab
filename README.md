# Unreal Engine 5 C++ | Ownership, Replication, Network Roles & Authority – Multiplayer Fundamentals

Unreal Engine 5 multiplayer networking tutorial covering replication, network roles, GameMode, PlayerController, GameState, PlayerState, local control, ownership, and RPCs.

[Watch the video tutorial on YouTube](https://youtu.be/1ZZUOe2AnTE)

The `main` branch uses Unreal Engine 5.8. The video was recorded with Unreal Engine 5.7. If you want to use the same engine version as in the video, check out the [5.7 branch](https://github.com/kaijurgeit/UE5NetRolesLab/tree/ue5.7).

## Getting started

```
git clone https://github.com/kaijurgeit/UE5NetRolesLab.git
```

1. Clone the repository
2. Open `NetRolesLab.uproject` with Rider, or right-click the `.uproject` file and select **Generate Visual Studio project files**, then open the project with Visual Studio
3. Build the project
4. Open `NetRolesLab.uproject` and start developing
